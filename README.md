# Physics of Nanomaterials Laboratory

## Overview

This repository contains experimental data, analysis code, and documentation from the **Physics of Nanomaterials** course offered at **Universitat Autònoma de Barcelona**. The course provides hands-on experience in synthesizing, characterizing, and analyzing nanomaterials through a series of carefully designed experiments.

## Course Information

- **Institution**: Universitat Autònoma de Barcelona
- **Course**: Physics of Nanomaterials (Laboratory)
- **Academic Year**: 2025-2026

## Objectives

This laboratory course aims to:
- Understand the fundamental principles governing nanomaterial properties
- Master experimental techniques for nanomaterial synthesis and characterization
- Develop skills in data analysis and scientific interpretation
- Explore the relationship between material structure and macroscopic properties at the nanoscale

## Experiments Conducted

### 1. Photoluminescence of Semiconductor Quantum Dots: The Influence of Size on Emission Energy

**Objective**: Investigate how quantum confinement effects influence the photoluminescence properties of semiconductor quantum dots and determine the relationship between particle size and emission wavelength.

**Key Topics**:
- Quantum confinement and bandgap engineering
- Photoluminescence spectroscopy fundamentals
- Size-dependent optical properties of nanomaterials

**Branch**: `quantum-dots`

---

### 2. Thermal Conductivity Measurement with the 3-Omega Method

**Date Conducted**: May 6, 2026

**Objective**: Measure the thermal conductivity of thin films and nanomaterials using the 3-omega (3ω) method, a sensitive and non-destructive characterization technique.

**Key Topics**:
- Heat transport in low-dimensional systems
- Frequency-dependent impedance analysis
- Thin-film thermal properties

**Branch**: `thermal-conductivity`

---

## Repository Structure

Each experiment is organized in its own dedicated branch to maintain clear separation of:
- Raw experimental data
- Data processing scripts
- Analysis notebooks
- Plots and visualizations
- Supporting documentation

To explore a specific experiment, checkout the corresponding branch:

```bash
git checkout quantum-dots
git checkout thermal-conductivity
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/miiriamus/Lab_Nanomaterials.git
   cd Lab_Nanomaterials
   ```

2. Switch to the experiment branch of interest:
   ```bash
   git checkout <branch-name>
   ```

3. Review the experiment-specific README and data files in that branch
